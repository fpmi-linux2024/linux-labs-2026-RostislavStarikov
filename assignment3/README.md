## task1.sh – временное игнорирование SIGINT

**Назначение:** показывает, как временно игнорировать Ctrl+C в определённой части сценария, затем восстановить стандартное поведение.

**Что происходит:**
1. Основная часть: Ctrl+C прерывает сценарий.
2. Временная часть: Ctrl+C игнорируется (5 секунд).
3. После восстановления: Ctrl+C снова прерывает.

**Основные приёмы:**
- `trap '' SIGINT` – игнорирование сигнала
- `trap -p SIGINT` – сохранение текущей обработки
- `eval "$old_trap"` – восстановление обработки

## archive_by_user.sh – архивация файлов пользователя

**Назначение:** архивирует все файлы указанного пользователя в указанном каталоге; перехватывает SIGUSR1 для сохранения списка файлов без архивации.

Функции сценария

| Функция | Назначение |
|---------|------------|
| `find_user_files()` | Поиск всех файлов пользователя в каталоге (рекурсивно) |
| `archive_files()` | Создание архива `user_files.tar.gz` с найденными файлами |
| `handle_sigusr1()` | Обработчик SIGUSR1 – сохраняет список файлов в `/tmp/user_list.txt` и завершается без архивации |

### Логика работы

1. Проверка аргументов (имя пользователя, каталог)
2. Проверка существования пользователя (`id`)
3. Проверка существования каталога (`-d`)
4. Установка обработчика `trap handle_sigusr1 SIGUSR1`
5. Поиск файлов и создание архива (или обработка SIGUSR1)

Результаты работы

| Сценарий | Результат |
|----------|-----------|
| Обычный запуск | Создаётся архив `user_files.tar.gz`, выводится путь и размер |
| Отправка SIGUSR1 | Список файлов сохраняется в `/tmp/user_list.txt`, архив не создаётся |
